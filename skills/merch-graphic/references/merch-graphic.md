# Merch Graphic References

Last reviewed: 2026-09-15

Merchandise graphic は flat artwork ではなく、product / substrate / process / placement / use context を含む最終物として観察する。

## Production-process evidence

- [Printful — DTG design file guidance](https://www.printful.com/jp/creating-dtg-file)
  - Observe: substrate composition, print sharpness/softness, transparency, color conversion, final-size resolution.
  - Useful for: digital textile print が source artwork と fabric に依存することの確認。
  - Avoid copying: one vendor's DPI/file-format values as universal rules.

- [Printful — Prepare design for embroidery](https://help.printful.com/hc/en-us/articles/28727397325340-How-should-I-prepare-my-design-for-embroidery)
  - Observe: flat vs puff vs other embroidery behavior, small-detail loss, thread/material interpretation.
  - Useful for: embroidery を raster print の代替出力と考えないための process evidence.
  - Avoid copying: vendor-specific minimum dimensions as universal design law.

- [Cotton Bureau — Embroidery specs](https://support.cottonbureau.com/article/202-what-size-should-my-hat-artwork-be)
  - Observe: digitization/stitch interpretation, detail/gap/text survival, distortion by product/material.
  - Useful for: mockup と stitched result の差、および final-size simplification の必要性。
  - Avoid copying: exact size thresholds outside Cotton Bureau's production context.

## Finished merchandise / collection evidence

- [Studio Moross — Kylie Vegas Residency Merch](https://www.studiomoross.com/work/kylie-vegas-merch)
  - Observe: one residency concept translated across tees, hoodie, cap, embroidered bomber, cards, keychain, pins, and coasters; wordmark/lockup and image/type treatments change by object.
  - Useful for: collection-level retained identity vs product-specific execution.
  - Avoid copying: Kylie/Voltaire assets, colors, motifs, or exact product mix.

- [Studio Moross — Spice World 2019](https://www.studiomoross.com/work/spice-world-2019-feature)
  - Observe: tour identity moving across stage, screen, apparel, and programme; nostalgia/legacy relationship and merchandise as one part of a larger visual world.
  - Useful for: campaign/key-visual → merchandise boundary and identity continuity.
  - Avoid copying: Spice Girls marks, maximalist vocabulary, or nostalgia as a generic merch rule.

- [Pentagram — Republic Records](https://www.pentagram.com/work/republic-records)
  - Observe: a recognizable identity motif extending from print/digital promotion into CDs and apparel.
  - Useful for: identity-bearing graphic can survive multiple carriers without merchandise becoming the identity source of truth.
  - Avoid copying: Republic emblem, monochrome palette, or exact motif behavior.

- [MoMA Design Store — MoMA Pattern Skyline T-Shirt](https://store.moma.org/products/moma-pattern-skyline-cotton-t-shirt)
  - Observe: a motif originating in another artifact family extended across shirt, bags, blocks, notebooks, umbrellas, and socks; product family rather than one canvas.
  - Useful for: cross-product motif adaptation and licensed/collaborative product evidence.
  - Avoid copying: MoMA logo, Peagreen artwork, NYC motif, or product assortment.

- [MoMA Design Store — MoMA × UNIQLO Gustav Klimt Poster T-Shirt](https://store.moma.org/products/moma-uniqlo-gustav-klimt-poster-t-shirt)
  - Observe: existing exhibition artwork is deliberately reframed as wearable licensed merchandise with front/back ownership rather than treated as a new original graphic.
  - Useful for: artwork-reproduction / attribution / rights boundary and front-back distribution.
  - Avoid copying: artwork, museum identity, or assuming poster reproduction is a default merch strategy.

## Compare across references

比較時は次を確認する。

| Axis | Questions |
| --- | --- |
| Job | identity signaling, collectible, souvenir, artwork reproduction, campaign extension のどれか |
| Product | flat apparel, structured garment, cap, card, pin, keychain, bag 等で surface ownership がどう変わるか |
| Placement | front/back/sleeve/edge/object face をどう分担しているか |
| Scale | authoring canvas ではなく body/object 上でどう見えるか |
| Process | ink / digital print / stitch 等が detail, edge, texture, color に何をするか |
| Substrate | garment/object color, weave, pile, stretch, shape が artwork にどう参加するか |
| Family | retained cue と product-specific variation は何か |
| Truth / rights | brand, artist, artwork, collaboration, attribution の ownership は明確か |
| Verification | mockup の先に proof/sample/final object で何を確認すべきか |

## Repeated findings

- merchandise は artwork と substrate/process の合成結果であり、blank mockup 上の flat composition だけでは判断できない。
- 同じ identity/campaign でも商品ごとに surface、使用状態、加工が違うため、literal duplication より product-specific translation が必要になる。
- screen/digital print/embroidery は detail・color・edge・texture の成立条件が異なる。production constraint は artwork design の早い段階へ戻す。
- merchandise collection の consistency は同一 placement/graphic の反復ではなく、recognition cue と variation logic で作れる。
- artwork reproduction / artist merchandise / brand merchandise では source ownership と approved use が design truth の一部になる。
- mockup は scale/placement/context の仮説確認には使えるが、ink/thread/substrate の最終 reproduction を証明しない。
