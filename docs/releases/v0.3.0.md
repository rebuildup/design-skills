# v0.3.0 — 2026-09-17

v0.3.0 expands `design-skills` from the initial layout / typography / supporting-skill surface into a broad reference-driven 2D design library covering UI foundations, platform adapters, artifact design, motion/video production, accessibility, and cross-device concerns.

## Shipping status

The canonical per-Skill shipping classification is [`../release-status-v0.3.0.json`](../release-status-v0.3.0.json).

- **82** public Skills are included in the release surface.
- **7** previously released Skills remain `stable`.
- **75** Skills ship as `trial-pending`; they are public and usable, but still require the documented real-project/artifact or adapter trial before promotion.
- No v0.3.0 Skill is promoted to `stable` solely because it landed on the release branch.

## Highlights

### UI and accessibility foundations

Adds focused Skills for color, iconography, data visualization, forms, tables, navigation, interaction state, keyboard/touch interaction, content, internationalization, dark/high-contrast modes, print-for-web, cognitive/inclusive design, cross-device behavior, information density, visual hierarchy, and reduced motion.

`interaction-state` is the single canonical owner for observable interaction state. The overlapping `interaction-states` candidate was removed before release.

### Platform / design-system adapters

Adds adapters for Apple HIG, Material, Fluent 2, Adobe Spectrum, IBM Carbon, Atlassian, Shopify Polaris, Salesforce Lightning, SAP Fiori, GitHub Primer, Ant Design, GOV.UK Design System, and USWDS.

Adapters translate current official guidance into the current product context rather than copying framework component catalogs or promoting platform-specific rules to universal design rules.

### Artifact design

Adds reference-driven Skills for slides, documents, diagrams, thumbnails, album covers, posters, key visuals, event flyers, OG images, social cards, brand identity, brand marks, app icons, favicons, merchandise graphics, signage, maps, and infographics.

### Typography, motion, and video

Adds font mixing, vertical writing, numeric typography, compositing, focused motion audit/implementation/review operations, hand-drawn and limited animation, kinetic typography, MIDI/audio-reactive/loop/title-sequence/parallax/transition/motion-poster workflows, and lyric/camera/product-promo/music-promo/music-visualization video Skills.

## Release validation

The release branch includes `release-final-gate`, which validates the checked-out final head rather than the repository default branch. It verifies:

1. shipping-status manifest coverage for every public `skills/*` directory,
2. Skill frontmatter and canonical directory/name consistency,
3. local Markdown references and stale `future` routing,
4. Skills CLI discovery from the local checkout using `skills@1.6.0`,
5. isolated copy installation of every Skill from that same checkout,
6. an external reference-link freshness sweep, treating explicit 404/410 responses as release failures while reporting access-restricted or transient endpoints separately.

## Promotion after v0.3.0

`trial-pending` is not a hidden or unavailable state. These Skills are deliberately shipped for use and evaluation. Promotion requires the evidence defined by each Skill and the repository promotion criteria: representative real work, delivered-artifact inspection, recorded failures/revisions, coherent routing, and standalone discovery/install behavior.
