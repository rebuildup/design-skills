LOCAL-FIRST DISTRIBUTED TRACING & FLAMEGRAPH

手元と CI で、
マイクロ秒の回帰を逃さない。

Kestrel Trace は Rust / Go / TypeScript マイクロサービス向けのローカルファースト分散トレース＆フレームグラフプロファイラです。本番クラウド APM へデータを送らず、開発者の手元環境や CI 上でテールレイテンシ回帰を即座に特定します。

  • 18 MB 単一静的バイナリ (macOS / Linux)
  • Docker 不要
  • テレメトリ送信ゼロ
  • エアギャップ動作可能
18 MB static binary / Apache-2.0 
$brew install kestrel-trace/tap/kestrel
4ステップで試す 仕様ベンチマークを見る

対象: バックエンドエンジニア・プラットフォームエンジニア・SRE / Open-Source Core (Apache-2.0) 無料

kestrel diff main..HEAD --route POST /v1/checkout

          CORE CAPABILITIES
          
ローカル解析と CI ゲートを完結させる 6 つの主要機能

          

            重厚なコンテナ群やクラウド送信パイプラインを省き、レイテンシ回帰の原因特定から再発防止までを単一バイナリに集約しています。
          

        


        

          

            

              
                
              
              01
            

            
ゼロ設定 OTLP 取り込み

            

              kestrel watch --port 4317 を起動するだけで、gRPC / HTTP スパンをローカル SQLite + DuckDB リングバッファへ自動収集します。
            

            
kestrel watch --port 4317

          


          

            

              
                
              
              02
            

            
インタラクティブ Span Waterfall & Differential Flamegraph

            

              ブランチ間（main vs HEAD）の同一トレースを重ね合わせ、p99 レイテンシ回帰箇所をミリ秒差分で即座に強調表示します。
            

            
kestrel diff main..HEAD

          


          

            

              
                
              
              03
            

            
SQL & N+1 クエリ帰属

            

              重複するプリペアドステートメントを自動集約し、問題のクエリをアプリケーションの file:line へ直接リンクします。
            

            
SELECT * FROM sku_locks (14x) -> reserve.rs:156

          


          

            

              
                
              
              04
            

            
決定的な CI レイテンシ予算ゲート

            

              kestrel check --p99-max 120ms が閾値超過時に非ゼロ終了し、PR 添付用の自己完結型 HTML スナップショットを生成します。
            

            
kestrel check --p99-max 120ms

          


          

            

              
                
              
              05
            

            
オフライン完結・プライバシー保護

            

              18 MB 単一バイナリ、外部送信なし。顧客データや機密ペイロードを含むトレースをエアギャップ環境やローカル完結で検証できます。
            

            
18 MB static binary / 0 external egress

          


          

            

              
                
              
              06
            

            
クロス言語トレース連結

            

              W3C Trace Context を介して Rust (tracing)・Go (otel)・Node/Bun サービス間の呼び出しを単一タイムラインに統合します。
            

            
W3C traceparent: Rust + Go + Node/Bun
