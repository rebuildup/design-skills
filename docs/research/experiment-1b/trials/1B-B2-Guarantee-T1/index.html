CORE CAPABILITIES

マイクロサービス開発の現場に必要な 6 つの計測機能

クラウド APM の設定や Docker スタックの起動を待たずに、手元の端末と CI パイプラインで完結する設計です。

01 SQLite + DuckDB

ゼロ設定 OTLP 取り込み

kestrel watch --port 4317 を起動するだけで、gRPC / HTTP スパンをローカル SQLite + DuckDB リングバッファへ自動収集します。

kestrel watch --port 4317
02 main vs HEAD

Span Waterfall & 差分 Flamegraph

ブランチ間（main vs HEAD）の同一トレースを重ね合わせ、p99 レイテンシの回帰箇所をミリ秒差分で即座に強調表示します。

kestrel diff main..HEAD
03 file:line 帰属

SQL & N+1 クエリ帰属

重複するプリペアドステートメントを自動集約し、レイテンシを圧迫する N+1 クエリをアプリケーションの file:line へ直接リンクします。

SELECT * FROM sku_locks → ×14
04 Exit Code Gate

決定的な CI レイテンシ予算ゲート

kestrel check --p99-max 120ms が閾値超過時に非ゼロ終了し、PR に添付できる自己完結型の HTML スナップショットを生成します。

kestrel check --p99-max 120ms
05 Air-Gap Ready

オフライン完結・プライバシー保護

18 MB の単一バイナリで外部送信はゼロ。決済情報や個人情報を含む機密ペイロードをクラウドへ送らず、ローカル完結で安全に検証できます。

telemetry: disabled (0 bytes out)
06 W3C Trace Context

クロス言語トレース連結

W3C Trace Context を介して Rust（tracing）・Go（otel）・Node/Bun サービス間の呼び出しを単一タイムラインへ統合します。

Rust tracing ⇄ Go otel ⇄ Node/Bun
