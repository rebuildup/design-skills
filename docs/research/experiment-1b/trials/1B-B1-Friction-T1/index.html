Local-First Profiler · Rust / Go / TypeScript

手元と CI で、マイクロ秒のテールレイテンシ回帰を逃さない。

Kestrel Trace は、本番クラウド APM にデータを送らず、開発者のローカル環境や CI 上で分散トレースと差分フレームグラフを解析できるプロファイラです。バックエンドエンジニア・プラットフォームエンジニア・SRE のデバッグと回帰防止を単一バイナリで完結させます。

brew install kestrel-trace/tap/kestrel
  • 18 MB 静的バイナリ (macOS / Linux)
  • Docker 不要
  • テレメトリ送信ゼロ
  • エアギャップ環境対応

CORE CAPABILITIES

ローカルデバッグから CI ゲートまで、6 つの設計原則

クラウド APM の反映待ちや重いコンテナ群を排し、マイクロサービス開発の日常ループにそのまま組み込める機能を単一バイナリに統合しています。

01 OTLP gRPC / HTTP

ゼロ設定 OTLP 取り込み

kestrel watch --port 4317 を起動するだけで、gRPC / HTTP スパンをローカルの SQLite + DuckDB リングバッファへ自動収集します。

02 main vs HEAD

Span Waterfall & Differential Flamegraph

ブランチ間の同一トレースを重ね合わせ、p99 レイテンシの回帰箇所をミリ秒単位の差分で即座に強調表示します。

03 file:line 帰属

SQL & N+1 クエリ帰属

重複するプリペアドステートメントを自動集約し、ボトルネックとなったクエリをアプリケーションの file:line へ直接リンクします。

04 Exit Code Gate

決定的な CI レイテンシ予算ゲート

kestrel check --p99-max 120ms が閾値超過時に非ゼロ終了し、PR にそのまま添付できる自己完結型 HTML スナップショットを生成します。

05 Zero Egress

オフライン完結・プライバシー保護

18 MB の単一バイナリで外部送信はゼロ。機密ペイロードを含む本番相当トレースも、エアギャップ環境やローカル端末内で安全に検証できます。

06 W3C Trace Context

クロス言語トレース連結

W3C Trace Context を介して Rust (tracing)・Go (otel)・Node / Bun サービス間の呼び出しを単一のタイムラインへ統合します。

WORKFLOW

4 ステップで原因特定から CI 再発防止まで

既存のテストや負荷スクリプトをそのまま実行し、差分検出と予算チェックをローカルと CI で同一の CLI により自動化できます。各ステップをクリックすると対応する出力モデルを確認できます。
