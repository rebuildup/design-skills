Kestrel Trace は、ローカルファーストの分散トレース＆フレームグラフプロファイラ。本番クラウド APM にデータを送らず、開発機と CI でテールレイテンシ回帰を特定します。

  • 18 MB 単一静的バイナリ
  • 0 テレメトリ送信
  • Air-gap 動作可能
インストール 差分フレームグラフを試す

Differential Flamegraph

main と HEAD を重ねて、回帰だけを光らせる

同一トレースをブランチ間で重ね合わせ、差分をミリ秒で表示します。下は仕様の例（checkout.reserve_inventory の N+1）を元にしたモデル表現です。スパンを選ぶと詳細が見られます。

Workflow

4 コマンドで、検出から再発防止まで

  1. kestrel watch --port 4317

    ローカルコレクタを起動

  2. テスト / 負荷スクリプト実行

    既存のものでトレースを収集

  3. kestrel diff main..HEAD

    回帰スパンを特定

  4. kestrel check --p99-max 120ms

    CI に組み込み再発防止

Features

6 つの主要機能

ゼロ設定 OTLP 取り込み

kestrel watch --port 4317 を起動するだけ。gRPC / HTTP スパンをローカル SQLite + DuckDB リングバッファへ自動収集します。

Span Waterfall & Differential Flamegraph

main vs HEAD の同一トレースを重ね、p99 レイテンシ回帰箇所をミリ秒差分で即座に強調します。

SQL & N+1 クエリ帰属

重複するプリペアドステートメントを集約し、問題のクエリをアプリの file:line へ直接リンク。

決定的な CI 予算ゲート

kestrel check --p99-max 120ms は超過時に非ゼロ終了。PR 添付用の自己完結 HTML スナップショットを生成。

オフライン完結・プライバシー保護

18 MB 単一バイナリ、外部送信なし。機密ペイロードもローカルで検証できます。

クロス言語トレース連結

W3C Trace Context で Rust (tracing)・Go (otel)・Node/Bun 間の呼び出しを単一タイムラインに。
