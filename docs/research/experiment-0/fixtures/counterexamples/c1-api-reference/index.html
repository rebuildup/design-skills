Local OTLP Trace Ingest Reference

HTTP/JSON and gRPC specification for writing OpenTelemetry spans into a local Kestrel ring buffer.

POST /v1/traces

Accepts standard OpenTelemetry ExportTraceServiceRequest payloads encoded as Protocol Buffers (application/x-protobuf) or OTLP/JSON (application/json). Payloads are validated synchronously and appended to the local write-ahead log before returning HTTP 200.

Local-only bind: By default, the collector binds strictly to 127.0.0.1:4318 (HTTP) and 127.0.0.1:4317 (gRPC). Use --bind explicitly only on trusted LAN segments.

Query Parameters & Headers

NameTypeRequiredDescription
Content-TypeHeaderYesapplication/x-protobuf or application/json.
Content-EncodingHeaderNoSupports gzip and zstd compressed request bodies.
X-Kestrel-SessionHeaderNoAssociates incoming spans with a named comparison snapshot (e.g. main or pr-842).

Example OTLP/JSON Request

curl -X POST http://127.0.0.1:4318/v1/traces \
  -H "Content-Type: application/json" \
  -H "X-Kestrel-Session: head" \
  -d '{
    "resourceSpans": [{
      "resource": { "attributes": [{ "key": "service.name", "value": { "stringValue": "checkout-api" } }] },
      "scopeSpans": [{
        "spans": [{
          "traceId": "4bf92f3577b34da6a3ce929d0e0e4736",
          "spanId": "00f067aa0ba902b7",
          "name": "POST /v1/checkout",
          "startTimeUnixNano": "1764234000000000000",
          "endTimeUnixNano": "1764234000112000000"
        }]
      }]
    }]
  }'

Related CLI Flags

Pass --ring-mb 256 to adjust local ring-buffer retention, or --strict-w3c to reject spans with malformed traceparent identifiers during CI verification runs.
