本番へ送らず、
手元と CI で p99 回帰 を突き止める。

Kestrel Trace は Rust / Go / TypeScript マイクロサービス向けの分散トレース＆フレームグラフプロファイラです。クラウド APM へデータを送信せず、開発者の手元環境や CI 上でマイクロ秒単位のテールレイテンシ回帰を特定します。

CORE CAPABILITIES

ローカル開発と CI に最適化された 6 つの主要機能

バックエンドエンジニア・プラットフォームエンジニア・SRE が、重いコンテナ群やクラウド転送に頼らずレイテンシ回帰を原因箇所まで追うための機能セットです。

ゼロ設定 OTLP 取り込み

kestrel watch --port 4317 を起動するだけで、gRPC / HTTP スパンをローカル SQLite + DuckDB リングバッファへ自動収集します。

OTLP gRPC :4317 · HTTP :4318

Span Waterfall & Differential Flamegraph

ブランチ間（main vs HEAD）の同一トレースを重ね合わせ、p99 レイテンシ回帰箇所をミリ秒差分で即座に強調表示します。

main..HEAD · ミリ秒差分ハイライト

SQL & N+1 クエリ帰属

重複するプリペアドステートメントを自動集約し、問題のクエリをアプリケーションの file:line へ直接リンクして原因特定を短縮します。

Prepared Statement 集約 · file:line

決定的な CI レイテンシ予算ゲート

kestrel check --p99-max 120ms が閾値超過時に非ゼロ終了し、PR 添付用の自己完結型 HTML スナップショットを生成します。

Non-zero exit · 単一 HTML レポート

オフライン完結・プライバシー保護

18 MB 単一バイナリで動作し外部送信は一切なし。PII や決済データを含む機密ペイロードもエアギャップ環境で安全に検証できます。

18 MB Binary · Zero Telemetry

クロス言語トレース連結

W3C Trace Context を介して Rust（tracing）・Go（otel）・Node/Bun サービス間の呼び出しを単一タイムラインに統合します。

W3C traceparent · Rust / Go / Node / Bun
