手元の端末と CI で、

Kestrel Trace は Rust / Go / TypeScript マイクロサービス向けのローカルファースト分散トレース＆フレームグラフプロファイラです。本番クラウド APM へデータを送らず、Docker も起動せず、ブランチ間のテールレイテンシ悪化をその場で可視化します。

brew install kestrel-trace/tap/kestrel
配布形態
単一 18 MB バイナリ（macOS / Linux）
依存関係
Docker 不要・SQLite + DuckDB 内蔵
プライバシー
テレメトリ送信ゼロ・エアギャップ対応

CORE ARCHITECTURE · 6 CAPABILITIES

            
ローカル実行と決定的な CI 判定のために設計された 6 つの能力

          

        


        
        

          

            

              01 / INGESTION
              SQLite + DuckDB
            

            
ゼロ設定 OTLP 取り込み

            

              kestrel watch --port 4317 を起動するだけで、OTLP gRPC / HTTP スパンをローカルの SQLite メタデータ + DuckDB 分析用リングバッファへ自動収集。設定ファイルや外部 DB コンテナは不要です。
            

            
    
              
  • 起動即時に :4317 (gRPC) / :4318 (HTTP) をリッスン
    • 
              
  • メモリ 42 MB 規模の軽量リングバッファで開発機を圧迫しない
    • 
            

          


          

            

              02 / CI GATE
              Deterministic Exit
            

            
決定的な CI レイテンシ予算ゲート

            

              kestrel check --p99-max 120ms は閾値超過時に非ゼロコードで終了し、CI パイプラインで回帰を自動ブロック。同時に PR へそのまま添付できる自己完結型の HTML スナップショットを生成します。
            

            
    
              
  • 外部ダッシュボード不要で PR レビュアーがオフライン閲覧可能
    • 
              
  • main ベースラインとの差分アノテーションを自動抽出
    • 
            

          

        


        
        

          

            03
            

              
Span Waterfall & Differential Flamegraph

              
ブランチ間（main vs HEAD）の同一トレースを重ね合わせ、p99 レイテンシ回帰箇所をミリ秒差分で即座に強調表示します。

            

          


          

            04
            

              
SQL & N+1 クエリ帰属

              
重複するプリペアドステートメントを自動集約し、反復回数・合計加算時間とともにアプリケーションの file:line へ直接リンクします。

            

          


          

            05
            

              
オフライン完結・プライバシー保護

              
18 MB 単一静的バイナリ。外部へのテレメトリ送信は一切なく、決済情報や個人情報を含む機密ペイロードをエアギャップ環境で安全に検証できます。

            

          


          

            06
            

              
クロス言語トレース連結

              
W3C Trace Context を介して Rust（tracing）・Go（otel）・Node/Bun サービス間の呼び出しを単一の分散タイムラインに統合します。
