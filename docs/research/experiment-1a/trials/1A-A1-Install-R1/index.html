Kestrel Trace は Rust / Go / TypeScript マイクロサービス向けのローカルファースト分散トレース＆フレームグラフプロファイラです。本番 APM へデータを送信せず、手元環境と CI 上でマイクロ秒単位のテールレイテンシ回帰を特定します。

brew install kestrel-trace/tap/kestrel

6 CORE CAPABILITIES

収集から CI ゲートまで、単一バイナリで完結する 6 つの機能

01 ZERO-CONFIG INGESTION

ゼロ設定 OTLP 取り込み

kestrel watch --port 4317 を起動するだけで、gRPC / HTTP スパンをローカルの SQLite + DuckDB リングバッファ へ自動収集します。コンテナや設定ファイルは不要です。

Rust / Go / TS OTLP gRPC :4317
→
kestrel watch 18 MB Static Binary
→
SQLite + DuckDB Local Ring Buffer
04 DETERMINISTIC CI GATE

決定的な CI レイテンシ予算ゲート

kestrel check --p99-max 120ms が閾値超過時に非ゼロ終了し、PR 添付用の自己完結型 HTML スナップショットを生成。回帰をマージ前に機械的に遮断します。 

$ kestrel check --p99-max 120ms --out pr-report.html
FAIL p99 latency 186.4ms exceeded budget 120.0ms (+66.4ms)
↳ top offender: checkout.reserve_inventory (+84.0ms, 14× SQL)
↳ snapshot written: ./pr-report.html (self-contained, 148 KB)
exit status 1
02

Span Waterfall & Differential Flamegraph

ブランチ間（main vs HEAD）の同一トレースを重ね合わせ、p99 レイテンシ回帰箇所をミリ秒差分で即座に強調表示します。

03

SQL & N+1 クエリ帰属

重複するプリペアドステートメントを自動集約し、問題のクエリをアプリケーションの file:line へ直接リンクします。

05

オフライン完結・プライバシー保護

18 MB 単一バイナリ、外部送信なし。顧客データや機密ペイロードを含むトレースもローカル完結・エアギャップ環境で安全に検証可能です。

06

クロス言語トレース連結

W3C Trace Context を介して Rust（tracing）・Go（otel）・Node / Bun サービス間の呼び出しを単一タイムラインに統合します。
