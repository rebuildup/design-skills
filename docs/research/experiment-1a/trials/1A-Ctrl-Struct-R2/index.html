$ brew install kestrel-trace/tap/kestrel

CAPABILITIES · 6つの主要機能

          
クラウド APM の待ち時間を排し、ローカルで完結する計測基盤

          

            バックエンドエンジニア・プラットフォームエンジニア・SRE の日常的な調査と CI ゲート運用に必要な機能だけを、18 MB の単一バイナリに凝縮しています。
          

        


        

          

            

              01
              
            

            
ゼロ設定 OTLP 取り込み

            

              kestrel watch --port 4317 を起動するだけで、gRPC / HTTP スパンをローカルの SQLite + DuckDB リングバッファへ自動収集します。
            

            
OTLP gRPC :4317 · SQLite + DuckDB

          


          

            

              02
              
            

            
Span Waterfall & Differential Flamegraph

            

              ブランチ間（main vs HEAD）の同一トレースを重ね合わせ、p99 レイテンシ回帰箇所をミリ秒差分で即座に強調表示します。
            

            
main..HEAD · p99 ms diff

          


          

            

              03
              
            

            
SQL & N+1 クエリ帰属

            

              重複するプリペアドステートメントを自動集約し、問題のクエリをアプリケーション側の file:line へ直接リンクします。
            

            
prepared stmt 集約 → file:line

          


          

            

              04
              
            

            
決定的な CI レイテンシ予算ゲート

            

              kestrel check --p99-max 120ms がしきい値超過時に非ゼロ終了し、PR 添付用の自己完結型 HTML スナップショットを生成します。
            

            
exit code 制御 · HTML snapshot

          


          

            

              05
              
            

            
オフライン完結・プライバシー保護

            

              18 MB 単一バイナリで外部送信はゼロ。Docker 不要かつエアギャップ環境でも動作するため、機密ペイロードをローカル完結で検証できます。
            

            
Zero telemetry · Air-gap ready

          


          

            

              06
              
            

            
クロス言語トレース連結

            

              W3C Trace Context を介して Rust（tracing）・Go（otel）・Node/Bun サービス間の呼び出しを単一タイムラインに統合します。
            

            
Rust · Go · Node/Bun · W3C traceparent
