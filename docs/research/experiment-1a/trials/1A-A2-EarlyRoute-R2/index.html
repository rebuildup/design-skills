02 / LOCAL-TO-CI WORKFLOW

起動から CI ゲート組み込みまで、4 コマンドで完結

コンテナ群の立ち上げやクラウドアカウント発行を待たず、既存のテストや負荷スクリプトにそのまま接続できます。

  1. 01 Collect

    ローカルコレクタを即時起動

    kestrel watch --port 4317

    OTLP (gRPC / HTTP) ポートを待受。受信したスパンをローカルの SQLite + DuckDB リングバッファへゼロ設定で取り込みます。

  2. 02 Exercise

    既存テスト・負荷スクリプトを実行

    cargo test / go test / bun test

    普段の結合テストやベンチマークを流すだけで、W3C Trace Context 経由のクロス言語トレースを自動連結します。

  3. 03 Diagnose

    ブランチ差分で回帰スパンを特定

    kestrel diff main..HEAD

    checkout.reserve_inventory 内の SELECT * FROM sku_locks ×14（+84ms）のような悪化箇所をミリ秒差分で即座に抽出します。

  4. 04 Enforce

    CI 予算ゲートで再発を防止

    kestrel check --p99-max 120ms

    閾値超過時は非ゼロ終了し、外部サービス不要でブラウザ閲覧できる自己完結型 HTML スナップショットを PR 向けに生成します。

03 / CORE CAPABILITIES

分散トレースの「重さ」と「後追い」を断つ 6 つの設計

取り込み・差分解析・コード帰属・CI 強制・プライバシー・クロス言語連結を単一バイナリに統合しています。

01 · INGESTION OTLP gRPC / HTTP

ゼロ設定 OTLP 取り込み

kestrel watch --port 4317 を実行するだけで、標準 OTLP エクスポート先として機能します。内部ストレージは SQLite（メタデータ索引）+ DuckDB（列指向スパン集計） のリングバッファ構成で、Docker コンテナも外部 DB も不要です。

02 · ANALYSIS main vs HEAD

Span Waterfall & Differential Flamegraph

単一トレースを眺めるだけでなく、ブランチ間（main vs HEAD）の同一エンドポイントトレースを重ね合わせます。p99 テールレイテンシの悪化箇所だけをミリ秒差分で即座に強調表示し、ノイズに埋もれた性能劣化を見逃しません。

03 · ATTRIBUTION file:line リンク

SQL & N+1 クエリ帰属

ループ内で反復発行される同一プリペアドステートメントを自動集約し、呼び出し元の file:line へ直接紐づけます。クエリログとアプリコードを行き来する手間を省きます。

04 · CI GATE Self-contained HTML

決定的な CI レイテンシ予算ゲート

kestrel check --p99-max 120ms が予算超過時に非ゼロ終了し、CI ジョブを確実に停止します。同時に、外部ホスト不要で PR にそのまま添付できる自己完結型 HTML スナップショットを出力します。

05 · PRIVACY & AIR-GAP

オフライン完結・プライバシー保護

18 MB の単一静的バイナリ（macOS / Linux）で完結し、外部テレメトリ送信は一切ありません。顧客データや機密ペイロードを含む再現トレースも、社内ネットワークやエアギャップ環境から出さずに検証できます。

06 · POLYGLOT

クロス言語トレース連結

W3C Trace Context（traceparent）を介して、Rust (tracing)・Go (otel)・Node / Bun サービス間の呼び出しを単一のタイムラインに統合します。
